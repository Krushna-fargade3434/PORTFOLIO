# My Portfolio

A clean, responsive React portfolio built with Vite, Tailwind CSS, and Framer Motion. This site highlights projects, skills, and professional experience in a modern presentation.

## Features

- React 19 with Vite for fast development and production builds
- Tailwind CSS for responsive styling
- Framer Motion for smooth section and card animations
- Multi-page structure with Home, About, Skills, Projects, and Contact sections
- Clean UI optimized for recruiters and hiring managers

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Router DOM

## Scripts

- `npm install` — install dependencies
- `npm run dev` — start local development server
- `npm run build` — create production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint across the source files

## Project Structure

- `src/` — application source code
- `src/components/` — reusable UI components
- `src/pages/` — page views for the portfolio
- `public/` — static assets and media

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL shown in the terminal

## Notes

Update the content in `src/pages/` and `src/components/` to personalize the portfolio further.
